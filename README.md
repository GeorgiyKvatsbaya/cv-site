# cv-site

Personal business-card site — plain HTML/CSS generated by a ~150-line Node script. English at `/`, Russian at `/ru/`.

## Edit content

Everything lives in [`content/site.mjs`](content/site.mjs): profile, highlights, links, stack, experience.
Strings are `{ en, ru }`; anything starting with `TODO` is a placeholder and is listed by the build.

- **CV**: put `cv-en.pdf` / `cv-ru.pdf` into `public/` — the "Download CV" button appears automatically.
- **Projects**: cards on the home page from `projects` in `content/site.mjs`. Screenshots go to `public/projects/` as a light/dark pair (1280×800 JPEG); the one matching the theme is shown.
- **Stack icons** come from [simple-icons](https://simpleicons.org) by slug. Brands missing there (dbt, Tableau, …) render as a text badge; drop `public/icons/<slug>.svg` to override (optional `data-hex="RRGGBB"` on `<svg>` sets the hover colour). Multicolour marks: give each `<path>` a `style="--c:#RRGGBB"` — monochrome at rest, real colours on hover. dbt comes from simple-icons 13.0.0; the Tableau mark is the multicolour logo from Wikipedia.
- **Link previews (OG images)**: after changing name, role, tagline, featured stack or location, run `npm run og` and commit `public/og/` — the build warns when they are outdated.
- **Theme**: follows the system; the toggle in the top bar cycles system → light → dark and remembers the choice (localStorage).
- **Analytics**: Vercel Web Analytics (enable it in the Vercel dashboard). "Download CV" clicks are recorded as virtual pageviews `/cv-download/{en,ru}` — custom events need the Pro plan.
- **Colours**: tokens at the top of [`src/style.css`](src/style.css) (`--accent` etc.), light theme in the `prefers-color-scheme: light` block.

## Run

```sh
npm install
npm run dev     # http://localhost:3000, restarts on changes (refresh the page)
npm run build   # → dist/
npm run og      # regenerate link-preview images public/og/{en,ru}.png (needs local Chrome; CHROME=… to override path)
```

## Deploy

Vercel → Add New → Project → import this repo. Build settings come from `vercel.json`; every push to `main` deploys.
After the first deploy, set `siteUrl` in `content/site.mjs` to the production URL (used for canonical / hreflang / OG).

## Layout

```
content/site.mjs    content (edit this)
src/templates.mjs   page templates
src/style.css       theme
src/main.js         email de-obfuscation + scroll reveal (optional, site works without JS)
public/             copied as-is: favicon, icons, robots.txt, CV PDFs
build.mjs           builder + dev server
```
